## 🌦️ Featured Project: Atmos — Weather Intelligence

**Atmos** is a weather application designed to provide weather information through a modern, responsive interface. It combines a dark visual theme, glassmorphism styling, and pink and purple accents with live weather data.

### ✨ Features

* **City Search:** Search for weather information by city name.
* **Current Weather:** View temperature, weather conditions, and feels-like temperature.
* **Temperature Range:** Display daily high and low temperatures.
* **Weather Metrics:** View humidity, wind speed, atmospheric pressure, and visibility.
* **Sunrise and Sunset:** Display sunrise and sunset times.
* **Hourly Forecast:** Explore upcoming forecast entries.
* **Five-Day Forecast:** View upcoming weather conditions and temperatures.
* **Loading Indicator:** Display feedback while weather information is being fetched.
* **Error Handling:** Show messages for empty searches and unsuccessful requests.
* **Responsive Interface:** Adapt the layout for different screen sizes.
* **API Key Protection:** Use Vercel serverless functions to retrieve weather data without placing the API key directly in the frontend JavaScript.

### 🛠️ Technologies Used

* **HTML5:** Application structure.
* **CSS3:** Responsive layouts, glassmorphism, gradients, and visual styling.
* **JavaScript:** API requests, dynamic weather updates, forecast rendering, and input validation.
* **OpenWeatherMap API:** Weather and forecast data.
* **Vercel Serverless Functions:** Server-side API requests and API key protection.
* **GitHub:** Source code management.
* **Vercel:** Application deployment.

### 🌐 Live Demo

**[Launch Atmos — Weather Intelligence](https://atmos-weather-intelligence.vercel.app/)**

### 🔐 API Key Security

Atmos uses the `OPENWEATHER_API_KEY` environment variable to keep the weather API key on the server side.

The frontend requests weather data through serverless endpoints instead of directly including the secret API key in browser-side JavaScript.

The `.env` file and Vercel's local configuration directory should not be committed to the public repository. The API key should be configured through Vercel's environment variable settings.

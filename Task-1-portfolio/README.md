# 🌐 Personal Developer Portfolio

A responsive personal developer portfolio built with **HTML, CSS, and JavaScript** to showcase my technical skills, projects, background, and contact information.

This project is part of my **Datheon Full Stack Web Development Internship**.

## 👨‍💻 About Me

Hi! I'm **Mohammed Shameem**, a B.Sc. Computer Science graduate interested in web development and building interactive web applications.

This portfolio introduces me, highlights my technical skills and projects, and provides a way to connect with me.

## ✨ Features

* **Home Section:** Introduction and quick access to important links.
* **About Section:** Information about my background and interests.
* **Skills Section:** Overview of my technical skills.
* **Projects Section:** Showcase of my development projects.
* **Contact Section:** Links for connecting with me.
* **Responsive Design:** Adapts the layout for desktop, tablet, and mobile screens.
* **Hamburger Navigation:** Collapsible navigation menu for smaller screens.
* **Dark and Light Themes:** Switch between dark and light appearances.
* **Theme Persistence:** Saves the selected theme using browser local storage.
* **Smooth Scrolling:** Provides smooth navigation between sections.

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* SVG icons
* Local Storage API

## 🎨 Design

The portfolio uses a dark background with neon purple and pink accents. The light theme provides an alternative appearance with light backgrounds and dark, readable text.

The layout is designed to provide a consistent experience across different screen sizes.
